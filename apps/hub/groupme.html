GroupMe

Pull recent messages from one GroupMe group into Digest (plans, deadlines, links). Uses your personal access token — secrets stay in the Windows keychain.

Status

Loading…

1 · Get an access token

  1. Open dev.groupme.com and sign in.
  2. Click your name → Access Token (or create an application and copy the token).
  3. Paste it below. Treat it like a password.

2 · Choose a group

After the token is saved, load groups and pick one — or paste a group id from the GroupMe URL (…/chats/GROUP_ID/…).

After connect

  1. Click Test pull (or Setup → Run connectors once).
  2. Open Digest — chat plans show under Today / Watching.
