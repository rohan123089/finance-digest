Gmail

Connect a dedicated Gmail (or your main one) so the hub can pull statements, deadlines, and reading links into Digest. Laptop-only — secrets stay in the OS keychain.

1 · Google Cloud (one-time)

  1. Open Google Cloud Console → create/select a project.
  2. Enable Gmail API.
  3. OAuth consent screen → External → add your new Gmail as a test user.
  4. Credentials → Create OAuth client → type Web application.
  5. Add this exact redirect URI:

http://127.0.0.1:8787/api/gmail/callback

Copy client id + secret from the downloaded JSON into step 2.

2 · Save client credentials

3 · Connect inbox

Sign in with the Gmail you want the hub to read (your new digest account is ideal). Forward school Outlook there if you want those messages too.

After connect

  1. Click Test pull (or run connectors live from the hub).
  2. Open Digest and refresh.
  3. UWCU statement emails become import reminders in Today.
