Gmail

Connect up to 3 Gmail inboxes with one Google Cloud OAuth client. Secrets stay in the OS keychain and reload after refresh.

1 · Google Cloud (one-time)

  1. Open Google Cloud Console → create/select a project.
  2. Enable Gmail API.
  3. OAuth consent screen → External → add each Gmail as a test user (all 3).
  4. Credentials → Create OAuth client → type Web application.
  5. Add this exact redirect URI:

http://127.0.0.1:8787/api/gmail/callback

One client id/secret covers all three inboxes.

2 · Save client credentials

3 · Connect inboxes (3 slots)

Use a different Google account for each slot. Google will show an account picker.
